# links - динамический редирект для QR на визитке

QR на визитке ведёт на неизменный адрес **https://dmytromfx-png.github.io/links/c/**.
Куда с него перекинуть (PDF-каталог, сайт, соцсети) - решаешь ты в любой момент,
правя одну строку. Перепечатывать визитки не нужно.

## Как переключить QR на другое

1. Открой на github.com файл `c/index.html`.
2. Нажми карандашик (Edit).
3. В строке `var TARGET = "...";` впиши новый адрес.
   Ту же ссылку продублируй в строке `<meta http-equiv="refresh" ...>` ниже.
4. Commit changes.
5. Через 1-2 минуты тот же QR ведёт уже на новый адрес.

## Каталог

Файл каталога кладётся в корень репозитория под именем `catalog.pdf`
(перетаскиванием через веб-интерфейс GitHub). Тогда адрес
`https://dmytromfx-png.github.io/links/catalog.pdf` открывает его прямо в браузере.
